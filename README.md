# FORMA

Полноценный русскоязычный сайт архитектурной студии по [макетам Figma](https://www.figma.com/design/OJlxFgyAOwVEhFOXXW61Dl).

## Запуск

Node.js 22 и npm. [Опубликованный сайт](https://forma-studio-orpin.vercel.app).

```sh
npm ci
npm run dev
```

Сайт открывается на http://localhost:3000.

## Возможности

- Главная, студия, каталог и шесть отдельных проектов, услуги и шесть отдельных услуг, журнал и три статьи, контакты, калькулятор, конфиденциальность и 404.
- Адаптивы 390 / 768 / 1280 / 1440 px, локальные кириллические шрифты и оптимизация изображений через Next.js.
- Фильтры каталога, hero-карусель, аккордеоны, непрерывное сравнение до/после, доступная галерея с клавиатурным управлением, мобильное меню.
- Настоящий многошаговый калькулятор: площадь 30–500 м², тип объекта, стиль и услуги влияют на иллюстративную оценку. Конфигурация сохраняется в браузере.
- Форма по запросу владельца является заглушкой: клиентская и серверная валидация, ошибки и состояния загрузки/завершения. Контакты и сообщения не сохраняются и не отправляются.
- Статические страницы проектов, услуг и статей, метаданные, Open Graph, sitemap.xml, robots.txt.
- Поддержка prefers-reduced-motion, семантические поля и native dialog с управлением фокусом.

## Проверки

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Если Chromium уже установлен системно, можно задать PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium.

## Деплой

Проект связан с GitHub и Vercel. Ветка main — production; изменения проходят проверки в GitHub Actions. Секреты для демонстрационной формы не требуются. Переменная SITE_URL необязательна: Vercel production hostname подставляется автоматически.
